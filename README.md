# SwiftRoute — Mini Courier Planner (Flask Prototype)
## Run on Windows
1. Extract ZIP.
2. Open this folder in File Explorer.
3. Double-click `run.bat` (internet is needed the first time to install Flask).
4. Open http://127.0.0.1:5000 in your browser.
## Run from terminal
`python -m pip install -r requirements.txt`
`python app.py`
Then visit http://127.0.0.1:5000.
## Features
Add/delete parcels, Merge Sort priority ordering, 0/1 Knapsack packing, Dijkstra shortest distances, Nearest-Neighbor TSP route, runtime snapshot, JSON report.
## Prototype scope
This is a working academic prototype using sample parcel data and a small static road graph. It does not connect to live GPS, traffic, maps, or courier APIs.
